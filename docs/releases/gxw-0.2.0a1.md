# GXW 0.2.0a1 프리뷰

기존 `gxw-parser-toolkit`의 읽기 전용 업데이트다. 전체 프로젝트 판독이나 현장 적용 승인본은 아니다.

- 고정 SHA와 허용 root를 사용하는 inventory, inspect, 직접 참조 query, 제한 compare와 Read-V1/snapshot을 제공한다.
- 등록 프로젝트 ID를 사용하는 로컬 서비스와 stdio MCP, 기본 summary-only와 운영자의 프로젝트별 상세 grant를 제공한다.
- 입력 파일 수정 없이 미인식 member, unknown 명령, 미해결 edge와 PARTIAL 상태를 보존한다.
- wheel/sdist는 읽기 모듈 11개와 읽기 진입점 5개만 포함한다. 이전 작성/인코딩 명령은 이 프리뷰에 포함하지 않는다.

새 가상환경에서 설치한다. 이전 GXW 배포물이나 별도 읽기 후보와 함께 설치하지 않는다. 기존 통합 환경, 소비 pin과 다른 패키지 버전은 독립적으로 유지한다.

[설치, 설정과 지원 한계](../gxw-read-v1.md)를 확인한다. Windows CPython 3.13 설치와 합성 시험을 검증 대상으로 삼는다. 다른 환경의 실제 동작을 동일하게 검증했다고 표현하지 않는다. 공개 시험은 합성 계약 검사이며 전체 파일 의미, 공식 프로그램 또는 PLC 실행 수락을 제공하지 않는다.
