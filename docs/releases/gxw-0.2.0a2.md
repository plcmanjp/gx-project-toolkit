# GXW 0.2.0a2 프리뷰

`gxw-parser-toolkit 0.2.0a2`는 기존 읽기 전용 프리뷰의 실행 조건과 자원 제한 처리를 보강한다.

- 등록 서비스와 작업 프로세스의 실행 조건을 확인하고, 조건을 충족하지 못하면 요청을 거부한다.
- 작업 프로세스의 메모리 제한을 적용하고, 적용 여부를 확인하지 못하면 요청을 진행하지 않는다.
- 작업 프로세스 정리에 실패한 서비스는 후속 요청을 거부한다. 원인을 해결한 뒤 새 서비스 인스턴스로 시작한다.
- 읽기 모듈 11개, 읽기 진입점 5개와 기존 읽기 형식의 지원 범위를 유지한다. 결과의 `PARTIAL`, `complete_search: false`와 미해결 상태도 유지한다.

새 가상환경에 개별 설치한다. 이전 GXW 배포물과 함께 설치하거나 기존 환경의 소비 버전을 자동으로 변경하지 않는다.

[설치, 설정과 지원 한계](../gxw-read-v1.md)를 확인한다. 설치 검증은 합성 시험 파일 3개, 총 41개 시험을 대상으로 한다. 합성 시험 통과는 전체 POU 판독, CPU 적법성, GX 검사 또는 실제 PLC와 현장 적용 승인을 제공하지 않는다.
