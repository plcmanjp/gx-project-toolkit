# Use and redistribution policy

[English](usage-rights-policy.md) | [한국어](usage-rights-policy-ko.md)

Publish only independently authored implementations for file-format interoperability and minimal synthetic regression tests. Do not include original projects, customer data, official exports, manufacturer binaries, manuals or screenshots. Do not bypass passwords or security features of protected projects.

Confirmation of rights for a specific decision table does not authorize redistribution of external materials. Including third-party code requires review of the rights and required notices for the exact files and versions. Passing technical tests does not resolve legal uncertainty.
