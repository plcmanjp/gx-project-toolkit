# FX5 MIL 위치결정 명령과 스칼라 주소 판독

이 기능은 저장된 원본 명령을 중립 IR로 읽는다. 대상 CPU의 명령 지원,
매개변수 적합성, GX 가져오기와 PLC 운전을 승인하지 않는다.

## 판독 범위

| 내부 표기 | 형식과 피연산자 | 읽은 명령 |
| --- | --- | --- |
| PLSV | A32/Aea/Abl, D/Y/Y | DPLSV |
| DSZR | A32/A32/Aea/Abl, D/D/K_1/M | DDSZR |
| DRVA | A32/A32/Aea/Abl, D/D/K_1/M | DDRVA |

모두 비펄스 coil이며 정확한 타입, 장치 종류, 인수 수와 원시 직렬화가
일치해야 한다. 32비트 표기를 보존하며 내부 표기를 그대로 출력하지 않는다.
다른 폭, 펄스, 태그, 음수 주소, 추가 인수와 미관측 metadata는 거부한다.

DX는 B 접점의 AND/OR 형식에서 16진수 주소로 읽는다.
SD는 비펄스 MOV의 A16/A16 및 A32/A32 형식에서 D/SD 양방향을 읽고,
EQ의 A32s/A32s LOAD/AND 형식에서 SD/D 조합을 읽는다.
두 장치는 일반 스칼라 허용 목록에 추가하지 않는다.

## 근거와 검증의 한계

명령 이름과 폭은 설치된 명령 카탈로그 및 동일 원본의 독립적인 래더
표현과 대조했다. 이는 공식 재내보내기나 장비 실행 증거와 구분한다.
고객 원본, 주소, 카탈로그 사본과 검증 출력은 공개 저장소에 포함하지 않는다.

공개 회귀는 독립적으로 만든 합성 값으로 폭, 진법, 순서, 부정 입력,
미지원 형식의 차단을 검사한다. 합성 회귀의 통과는 현장 적합성을 뜻하지 않는다.
